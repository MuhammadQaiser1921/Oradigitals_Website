# Quick Start (Express)

## 1. Install

```bash
npm install
```

## 2. Run

```bash
npm run dev
```

Open `http://localhost:3000`.

## 3. Edit Content

Primary content source:

- `src/data/site-content.js`

Update:

- Site/company info
- Page sections
- Cards, lists, testimonials, jobs, CTAs

## 4. Edit Templates

- `src/views/page.ejs`
- `src/views/components/*.ejs`

## 5. Edit Styles

- `public/express.css`

## 6. Production Start

```bash
npm start
```

## Notes

- Legacy Next files are archived under `archive/`.
- Active runtime is Express + EJS only.
